# TableNest

A simple, responsive restaurant management interface built with Angular.

## Core features
- Dashboard with total orders, revenue, and orders in progress
- Order management
- Menu management
- Table management
- Simple sign-in page with one demo-account shortcut
- Responsive dark interface with subtle multicolour accents

## Navigation
The main menu is intentionally limited to Dashboard, Orders, Menu, and Tables to keep common tasks easy to find.

## Run locally
1. Install Node.js (LTS).
2. Run `npm install`.
3. Run `npm start`.
4. Open the local URL printed in the terminal (usually `http://localhost:4200/`).

## Notes
